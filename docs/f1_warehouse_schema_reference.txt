2. dim_team
Grain: One row per team identity / validity period

KEY / CONSTRAINT NOTES

dim_driver
- PK: driver_key
- UNIQUE: driver_id

dim_team
- PK: team_key
- UNIQUE: (team_id, valid_from_season)

dim_circuit
- PK: circuit_key
- UNIQUE: (circuit_name, location, country)

dim_race
- PK: race_key
- FK: circuit_key -> dim_circuit.circuit_key
- UNIQUE: (season, round_number)

fact_race_results
- PK: race_result_key
- FK: race_key -> dim_race.race_key
- FK: driver_key -> dim_driver.driver_key
- FK: team_key -> dim_team.team_key
- UNIQUE: (race_key, driver_key)

fact_qualifying
- PK: qualifying_key
- FK: race_key -> dim_race.race_key
- FK: driver_key -> dim_driver.driver_key
- FK: team_key -> dim_team.team_key
- UNIQUE: (race_key, driver_key)

fact_lap_times
- PK: lap_key
- FK: race_key -> dim_race.race_key
- FK: driver_key -> dim_driver.driver_key
- FK: team_key -> dim_team.team_key
- UNIQUE: (race_key, driver_key, lap_number)

Surrogate keys (driver_key, team_key, circuit_key, race_key, race_result_key,
qualifying_key, lap_key) are auto-generated using PostgreSQL identity columns.
